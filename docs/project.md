==================================================
PROJECT CONCEPT
==================================================

Create a modern pet-care platform where customers can:

- Register / login
- Create profiles for multiple pets
- Store pet name, breed, species, age, weight, gender and notes
- Browse pet-care services
- Book grooming appointments
- Book veterinary consultations
- Book vaccination appointments
- Select available dates and time slots
- Manage upcoming and previous appointments
- Receive intelligent service recommendations
- Chat with an AI Pet Care Assistant
- Receive guidance personalized using their pet profile

Administrators should eventually be able to:

- Manage customers
- Manage pets
- Manage services
- Manage appointment availability
- Manage bookings
- Change booking statuses
- View dashboard statistics
- Configure schedules and blocked dates
